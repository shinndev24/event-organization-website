# Event Organization Platform Concept

A conceptual event organization platform UI built as a personal portfolio project.
This project is not affiliated with any real events organization company. All data and branding are fictional.

## Overview

This website is a front-end concept for a modern event organization and management platform. It was originally designed as a mockup for a company, but the design was not used. I have repurposed it as a personal portfolio piece, replacing all original branding, logos, and any content related with original work, keeping the structure and initial functions of the website.
Although I chose event organization, this page can come in handy for any kind of business offering services.

The project showcases:

- Clean, responsive UI built with React + Vite
- Private area with useful contents for clients
- Modular component structure
- Language toggle between two languages

## Tech Stack

- Vite
- React
- Leaflet
- CSS

## Features

- **Home** - Hero, search bar, services overview, quick lnks and news
- **Exploring experiences** - Search by areas(Within Spain´s borders) with an area selection in map option, results based on the chosen area and services related
- **Organizing events** - Formulary on organizer's data, crative process steps and services related
- **Services** - All services offered listed with detail and descriptions
- **Colaboration** - What we offer, testimonies and contact form
- **Work with us** - Introduction, reasons for joining and contact form
- **Contact** - Contact info and contact form
- **About us** - Brief description of the company, list of studios, journalism and responsabilities
- **Private area** - Mockup login and contents/ resources for clients
