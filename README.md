# Real Estate Platform Concept

A conceptual real estate platform UI built as a personal portfolio project.
This project is not affiliated with any real estate company. All data and branding are fictional.

## Overview

This website is a front-end concept for a modern real estate platform. It was originally designed as a mockup for a company, but the design was not used. I have repurposed it as a personal portfolio piece, replacing all original branding, logos, and client-specific content with original work.
This page can be handy for any kind of business offering services, but I kept the focus on a real estate company for this mockup.

The project showcases:

- Clean, responsive UI built with React + Vite
- Private area with useful contents for employees
- Modular component structure

## Tech Stack

- Vite
- React
- Leaflet
- CSS / SCSS modules

## Features

- **Home** - Hero, searcher, services overview, quick lnks and news
- **Buy page** - Search by areas(Within Spain´s borders) with an area selection in map option, results based on the chosen area and services related
- **Sell page** - Formulary on sellers' data, selling process steps and services related
- **Introduction to franchise** - Description, testimonies and formulary with data
- **Work with us** - Description, formulary with data
- **Contact** - Contact info and contact form
- **Private area** - Mockup login and contents/ resources for employees
